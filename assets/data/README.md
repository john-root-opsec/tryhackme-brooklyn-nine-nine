# Geographic data attribution

The animated README globe uses the **Natural Earth Admin 0 Countries, 1:110m** dataset.

- Source: https://github.com/nvkelso/natural-earth-vector/tree/master/geojson
- File: `ne_110m_admin_0_countries.geojson`
- Scale: 1:110m (generalized; suitable for a compact README globe, not cadastral or navigation use)
- Attribution: Natural Earth data is in the public domain.

The render script downloads this file on first use if it is not present locally. Country geometry is projected onto an orthographic sphere. The banner is a portfolio visual and does not represent live network telemetry or threat intelligence.
