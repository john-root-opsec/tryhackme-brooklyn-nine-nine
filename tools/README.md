# Tool Reference

This is a general-purpose reference for the technologies selected for the Brooklyn Nine-Nine learning project. It does not document target-specific commands, credentials, answers, or findings.

| Tool / technology | General purpose | Defensive learning angle |
|:--|:--|:--|
| Kali Linux | Security testing workstation | Understand a controlled assessment environment |
| Nmap | Network discovery and service identification | Reduce unnecessary exposed services |
| Gobuster | Web content discovery | Review unintended public resources |
| Hydra | Authentication security testing | Enforce strong authentication and rate limits |
| Wireshark | Packet and protocol analysis | Understand network visibility and encryption |
| SSH | Secure remote administration | Harden authentication and access policy |
| FTP | File transfer protocol | Identify cleartext transfer and anonymous-access risks |

## Responsible use

Use these tools only against systems you own or are explicitly authorized to test. A tool's availability does not grant permission to scan or authenticate to third-party systems.

Tool descriptions are intentionally high-level. Lab-specific findings are documented separately only when TryHackMe's room-sharing rules permit publication.
